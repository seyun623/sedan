# 카드사 로그인 방법 (PC 홈페이지 확인, 2026-11-25)

세윤님이 7개 카드사 공식 PC 홈페이지 로그인 화면을 직접 열어 확인한 결과입니다. 앱 안 브라우저의 기본 화면(PC/휴대폰)과 로그인 안내는 이 표를 따릅니다.

| 카드사 | 로그인 수단 | 휴대폰에서 가장 편한 방법 | 앱 안 기본 화면 |
|---|---|---|---|
| 현대카드 | 현대카드 앱(7자리 숫자·QR, 3분) · 간편번호 · 아이디 · 인증서 | 앱 7자리 코드 | PC |
| KB국민카드 | KB Pay(QR만, 10분) · PIN · 아이디(가상키보드 필수) · 공동인증서 | 휴대폰 화면의 아이디·KB Pay 번호·카드 인증 | 휴대폰 |
| 삼성카드 | 모니모페이(7자리·QR, 5분) · 아이디(직접 입력, OTP 추가) · 금융/공동인증서 | 모니모 7자리 코드 또는 아이디 | 휴대폰(같은 사이트) |
| 신한카드 | SOL페이(7자리·QR, 10분) · 신한인증서 · 간편로그인 · 아이디(직접 입력) · 공동인증서 | SOL페이 7자리 코드 또는 아이디 | 휴대폰(같은 사이트) |
| 롯데카드 | 로카페이(7자리·QR, 5분) · 아이디(가상키패드 필수) · 공동인증서 | 로카 7자리 코드 | PC |
| 하나카드 | 하나Pay(7자리·QR) · **토스·네이버 간편인증** · 아이디(가상키패드) · 공동인증서 | 토스·네이버 간편인증 | PC |
| 우리카드 | 우리WON페이(7자리·QR) · PIN · 아이디(새 브라우저 추가인증) · 인증서 | 휴대폰 화면 (PC는 보안프로그램 4종이 없으면 로그인 화면이 안 열림) | 휴대폰 |

## 앱에서 도와주는 것 (2.14.4)

- 로그인 화면 위에 카드사별로 가장 편한 방법을 💡로 안내합니다.
- 화면에 앱 7자리 코드가 나오면 위에 크게 보여 주고, **'복사하고 앱 열기'**를 누르면 코드를 복사한 뒤 카드사 앱(현대카드, 모니모, SOL페이, LOCA, 하나Pay, 우리WON카드 …)을 엽니다. 코드를 붙여 넣고 돌아오면 로그인된 화면이 그대로 남아 있습니다.

## 참고: 피클(Pickle)의 방식과 비교 (피클 AI 답변, 2026-11-25)

| | 피클 | 머니플로우 |
|---|---|---|
| 카드사 접속 | 회사 서버의 원격 브라우저 | 휴대폰 안 브라우저 (서버 없음) |
| 비밀번호 | 기기 키로 암호화해 보관 → 서버 보안 영역(Nitro Enclave)에서 풀어 자동 입력 | 저장하지 않음. 구글 비밀번호 관리자 자동 완성은 카드사가 허용하는 곳에서 동작 |
| 가상 키패드·앱 인증 | 사용자에게 제어권을 넘김 | 사용자가 직접 입력, 앱 7자리 코드 도우미 |
| 가져오는 것 | 결제 예정 금액, 카드별 실적 (필요한 메뉴만 열어 읽음) | 이용내역, 실적, 혜택 (화면 전체를 읽음) |
| 로그인 없이 | Gmail·네이버 메일의 카드 명세서 (월 청구 금액·결제일) | 결제 알림 자동 등록 |

### 가져올 점 (계획)
1. 결제 예정 금액·결제일 읽기 → 카드 계좌에 표시하고 결제일 알림에 사용
2. 카드사가 카카오톡·문자로 보내는 '결제 예정 금액 안내'를 자동 등록에서 읽기 (로그인 없이 매달 청구 금액)
3. 로그인 후 '필요한 것만 가져오기' 한 번으로 이용내역·결제 예정 금액·실적 화면을 차례로 읽기
4. 메일 명세서 연동은 구글 심사가 필요한 권한(Gmail 읽기)이라 보류. 2번으로 대신함
