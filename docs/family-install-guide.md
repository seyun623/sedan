# 가족용 설치·업데이트 안내

머니플로우는 Play 스토어 없이 APK 파일로 직접 설치해서 씁니다.

## 1. 처음 한 번: 서명 키 만들기
업데이트를 하려면 **모든 버전이 같은 키로 서명**되어야 합니다. 키가 바뀌면 폰이 업데이트를 거부합니다.

1. 내 컴퓨터에서 실행 (JDK 필요): `./scripts/create-release-keystore.sh`
2. 만들어진 `moneyflow-release.jks` 파일과 비밀번호를 **비밀번호 관리자 등에 꼭 백업**합니다. 저장소에는 올리지 않습니다.
   - 키를 잃어버리면 기존 앱을 업데이트할 수 없습니다. 앱을 지우고(데이터도 함께 지워짐) 새로 설치해야 합니다.
3. GitHub 저장소 → Settings → Secrets and variables → Actions에 4개를 등록합니다.
   - `ANDROID_KEYSTORE_BASE64`: `base64 -w0 moneyflow-release.jks` 결과 (macOS: `base64 -i moneyflow-release.jks`)
   - `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS`(`upload`), `ANDROID_KEY_PASSWORD`

## 2. 새 버전 APK 만들기
- 태그를 올리면 자동으로 빌드됩니다: `git tag v1.0.0 && git push origin v1.0.0`
  (또는 GitHub → Actions → "Release build" → Run workflow)
- 빌드가 끝나면 실행 화면 아래 **Artifacts**에서 `moneyflow-1.0.0` 압축 파일을 내려받으면 안에 `-basic.apk`와 `-autocapture.apk`가 있습니다.
- 버전 번호는 자동으로 올라가므로 새 APK는 항상 업데이트로 설치됩니다.

## 2-1. 두 가지 버전
| 파일 | 내용 | 설치 |
|---|---|---|
| `moneyflow-버전-basic.apk` (**기본판, 권장**) | 결제 알림·문자 자동 등록을 뺀 버전. 나머지 기능은 모두 같음 | 그냥 설치됨 |
| `moneyflow-버전-autocapture.apk` (자동 등록판) | 카드·은행 알림/문자로 거래 자동 기록 | 아래 "자동 등록판 설치" 필요 |

- 두 버전은 같은 앱입니다(앱 ID·서명 키 동일). 기본판을 쓰다가 자동 등록판을 덮어 설치해도 데이터가 그대로 남고, 반대도 됩니다.
- 한국에서는 구글 Play 프로텍트의 **"사기 방지 강화"** 기능이, 브라우저·메신저·파일 앱으로 받은 앱 중 **문자 수신이나 알림 접근 권한을 요청하는 앱의 설치를 막습니다** ("기기 보호를 위해 앱 차단됨"). 자동 등록판이 여기에 해당합니다.

### 자동 등록판 설치 (필요한 사람만)
방법 1 — Play 프로텍트를 잠시 끄고 설치:
1. Play 스토어 → 오른쪽 위 프로필 → **Play 프로텍트** → 오른쪽 위 ⚙️ → **"Play 프로텍트로 앱 검사"** 끄기
2. APK 설치
3. 같은 곳에서 **다시 켜기** (꼭 다시 켜 두세요)

방법 2 — 컴퓨터에서 USB로 설치 (개발자 옵션의 USB 디버깅 필요): `adb install moneyflow-버전-autocapture.apk`

## 3. 가족 폰에 설치하기
1. APK 파일을 폰으로 보냅니다 (카카오톡 나에게 보내기, 구글 드라이브, USB 등).
2. 폰에서 파일을 열고, "출처를 알 수 없는 앱 설치"를 물으면 해당 앱(카카오톡/파일 앱 등)에 허용합니다.
3. "Play 프로텍트" 경고가 나오면 **세부정보 → 그래도 설치**를 누릅니다. (Play 스토어에 없는 앱이라 나오는 일반 경고입니다.)

### 처음 실행 후 권장 설정
- **앱 잠금**: 자산 탭 오른쪽 위 ⚙️ → 앱 잠금 및 보안 → 앱 잠금 켜기 (PIN 4~6자리, 생체 인증 선택)
- **결제 자동 등록** (자동 등록판만): ⚙️ → 카드·은행 알림으로 자동 기록
  - Android 13 이상에서는 직접 설치한 앱의 알림 접근·문자 권한이 처음에 막혀 있습니다. 허용 화면이 회색이면:
    휴대폰 **설정 → 애플리케이션 → 머니플로우 → 오른쪽 위 ⋮ → "제한된 설정 허용"** 을 누른 뒤 다시 시도하세요.
  - 기본 등록 계좌를 정해 두면 카드사 이름과 맞는 계좌가 없을 때 그 계좌에 기록됩니다.

## 4. 업데이트하기
새 APK를 똑같이 열어 설치하면 됩니다. 기존 데이터는 그대로 남습니다.

## 5. 백업과 복원 (휴대폰을 바꿀 때)
데이터는 그 휴대폰 안에만 암호화되어 있습니다. **백업 파일**로 보관하거나 아래 5-3의 자동 백업을 켜 두세요.

**백업하기**: 자산 탭 ⚙️ → 백업 및 복원
- **백업 파일로 저장**: 휴대폰 저장공간(다운로드 폴더 등)이나 구글 드라이브를 골라 저장합니다.
- **백업 파일 보내기**: 카카오톡 "나에게 보내기", 메일 등으로 보냅니다.
- 백업할 때 정한 **비밀번호를 잊으면 그 파일은 아무도 열 수 없습니다.** 가족끼리 정해 둔 비밀번호를 쓰거나 따로 적어 두세요.
- 한 달에 한 번, 그리고 휴대폰을 바꾸거나 초기화하기 전에 꼭 백업하세요. 설정 화면에 마지막 백업 날짜가 보입니다.

**복원하기** (새 휴대폰)
1. 앱을 설치하고 처음 화면에서 **"백업 파일에서 복원하기"** (또는 ⚙️ → 백업 및 복원 → 백업 파일 불러오기)
2. 백업 파일을 고르고 비밀번호 입력 → 백업 내용(계좌·거래 수, 날짜)을 확인한 뒤 복원
- 복원하면 그 휴대폰에 있던 기록은 **모두 백업 내용으로 바뀝니다.**
- 백업 이후에 날짜가 지난 고정 거래는 복원 직후 자동으로 기록됩니다.
- 앱 잠금 PIN, 화면 테마, 자동 등록 설정은 백업에 들어가지 않으니 새 휴대폰에서 다시 설정하세요.

## 5-1. 카드사에서 내역·실적 가져오기
⚙️ → **카드사에서 가져오기** (또는 카드 계좌 화면의 "카드사에서 가져오기")
1. 카드사를 고르면 앱 안에서 카드사 홈페이지가 열립니다. 평소처럼 직접 로그인하세요 (카드사 앱 승인·인증 포함).
2. **이용내역·명세서·실적 화면**을 연 뒤 아래 **"이 화면 가져오기"** → 읽는 방법 선택
   - 기기에서 읽기: 밖으로 보내지 않음. 카드사 화면 모양에 따라 일부를 못 읽을 수 있음
   - AI로 읽기: AI 설정에서 고른 서비스로 화면 글자를 보내 정확하게 읽음 (켤 때마다 동의)
3. 미리보기에서 넣을 카드 계좌와 내역을 확인하고 **추가**. 같은 날 같은 금액이 이미 있으면 "이미 있음"으로 빼 둡니다. 취소 건은 원래 결제를 지웁니다.
4. 실적 금액이 화면에 있으면 카드 계좌에 저장되어 계좌 화면에서 볼 수 있습니다.
- **이 화면 기억하기 (2.1)**: 자주 보는 이용내역·실적·혜택 화면에서 눌러 두면, 다음부터는 로그인한 뒤 **"기억한 화면 N개 읽기"** 한 번으로 그 화면들을 차례로 열어 읽고 미리보기로 모아 보여 줍니다. 위쪽 책갈피 버튼에서 기억한 화면을 지울 수 있어요.
  - 메뉴를 눌러도 주소가 바뀌지 않는 화면은 다시 열 수 없어요. 그런 화면은 직접 열고 "이 화면 가져오기"를 쓰세요.
- 아이디·비밀번호는 저장하지 않고, 화면을 닫으면 로그인 기록을 지웁니다(다음엔 다시 로그인). 기억하는 것은 화면 주소뿐입니다.
- 카드사 홈페이지가 바뀌면 읽기가 안 될 수 있어요. 그때는 어느 카드사인지 알려 주세요.

## 5-2. 카드 실적·혜택 관리
자산 탭에서 카드 계좌를 누르면 **카드 실적**과 **카드 혜택**이 보입니다.
- **실적 조건 설정**: 전월 실적 기준 금액, 실적 기간 시작일(보통 1일, 결제일 기준 카드는 이용기간 시작일), 실적에서 빠지는 카테고리·단어(관리비, 세금, 상품권 등)
- **혜택 추가**: 예) 카페 10% 할인 · 월 한도 5,000원 · 전월 실적 30만 원 이상 / 스타벅스 건당 500원 · 5,000원 이상 결제
  - **AI로 등록** (AI 설정 필요): 카드사 앱·홈페이지의 카드 상품 안내에서 혜택 부분을 복사해 붙여 넣으면 혜택을 한 번에 만들어요. 등록 전에 할인율·한도를 확인하세요.
  - 카드사에서 가져오기로 로그인한 뒤 **혜택 안내 화면**에서 "이 화면 가져오기 → AI로 읽기"를 해도 됩니다.
- **어떤 카드로 낼까?**: 홈 화면 "어디서 어떤 카드?"에 카테고리·가맹점별로 가장 유리한 카드가 보이고, 지출을 입력할 때도 "○○카드로 내면 약 500원 혜택"을 알려 줘요. 전월 실적이 모자란 혜택과 한도를 다 쓴 혜택은 빼고 계산해요.
- 이번 기간 실적과 남은 금액, 받은 혜택과 남은 한도를 계산합니다. 홈 화면에도 카드별 실적이 보입니다.
- ⚙️ → **카드 실적·혜택 알림**을 켜면, 실적 기간이 5일 남았는데 모자랄 때와 혜택 한도를 다 썼을 때 알려 줍니다.
- 계산은 앱에 기록된 결제 기준입니다. 카드사 실적과 다를 수 있으니 "카드사에서 가져오기"로 가져온 카드사 실적과 비교해 보세요.

## 5-3. 자동 백업과 알림 (1.5)
- ⚙️ → 백업 및 복원 → **자동 백업** 켜기 → 백업 비밀번호 정하기 → 저장할 폴더 고르기 (구글 드라이브 폴더를 고르면 폰을 잃어도 안전)
- 매주(또는 매일) 백업 파일이 그 폴더에 쌓이고 최근 5개만 남겨요. 복원은 그 파일을 "백업 파일 불러오기"로 고르면 돼요.
- ⚙️ → 알림: 예산 알림(80%·100%), 매월 1일 지난달 요약, 백업 알림(2주 미백업·자동 백업 실패)

## 5-4. 할부·해외 결제·분류 규칙 (1.6)
- 지출 입력에서 결제 수단이 신용카드(또는 카드 계좌)면 **할부 개월**을 고를 수 있어요. 매달 지출로 나눠 기록하고, 카드 잔액에는 전액이 반영돼요.
- 자동 기록·카드사 가져오기의 할부를 나누려면 ⚙️ → **할부 결제 나눠 기록**을 켜세요.
- (자동 등록판) 해외 결제 문자가 오면 "원화 금액을 입력해 주세요" 알림이 와요. 카드사 앱에서 원화 금액을 확인한 뒤 알림을 눌러 금액만 넣으면 돼요.
- ⚙️ → **자동 분류 규칙**: "스타벅스 → 카페/간식" 같은 규칙, 기록하지 않을 알림("포인트 적립" 등)을 정해요.

## 5-5. 위젯·가족 합산·파일 가져오기·태그 (2.0)
- **위젯**: 홈 화면을 길게 눌러 위젯 → 머니플로우 지출. 앱 잠금이 켜져 있으면 금액을 가려요(⚙️ → 앱 잠금 및 보안에서 바꿀 수 있음).
- **가족 합산**: 가족이 각자 "백업 파일 보내기"로 파일을 보내 주면, ⚙️ → 가족 합산 보기 → 가족 백업 파일 불러오기 → 이름과 그 파일 비밀번호 입력. 새 백업을 받으면 그 사람을 눌러 "새 백업으로 바꾸기".
- **파일 가져오기**: ⚙️ → 카드사에서 가져오기 → 엑셀·CSV 파일에서 가져오기. 카드사·은행 홈페이지(PC)에서 이용내역을 엑셀로 받아 고르면 돼요. 옛 .xls 파일은 xlsx나 CSV로 저장한 뒤 고르세요.
- **태그**: 메모에 `#여행`처럼 붙이면 소비분석 → 태그별에서 모아 봐요.
- **(2.2) 고정 거래 제안**: 예산·목표 탭에서 "매달 반복되는 것 같아요" 카드가 보이면 "고정 거래로 등록"을 누르세요. 이번 달 것이 이미 있으면 다음 달부터 자동 기록돼요.
- **(2.2) 가족 예산**: 가족 합산 화면에서 "가족 예산 정하기". 위젯은 크기를 줄이거나 늘리면 보이는 내용이 바뀌어요.

## 6. 알아 둘 점
- **데이터는 폰마다 따로** 저장됩니다. 가족 간에 자동으로 공유·동기화되지 않습니다. (백업 파일을 다른 사람 폰에서 복원하면 그 폰의 기록이 바뀌니 주의하세요.)
- 앱을 삭제하면 그 폰의 데이터도 모두 삭제됩니다.
- 엑셀로 보고 싶을 때는 ⚙️ → 전체 거래 CSV 내보내기를 쓰세요. (CSV는 보기용이고, 복원은 백업 파일로 합니다.)

## 7. 처음 설치 후 확인할 것
자동 테스트로 확인할 수 없는 부분입니다.
- [ ] 샘플 데이터 불러오기 → 앱 완전히 종료 후 다시 열었을 때 데이터 유지
- [ ] 앱 잠금: PIN 설정 → 홈으로 나갔다 30초 뒤 돌아오면 다시 잠김 → 생체 인증 해제
- [ ] 최근 앱 화면에서 내용이 가려지는지
- [ ] (자동 등록판) 실제 카드 결제 알림/문자 → 1건만 기록되는지, 승인취소 시 원거래 삭제되는지
- [ ] 고정 거래가 지정한 날짜에 기록되는지
- [ ] 백업 파일 저장 → 다른 폰(또는 앱 삭제 후 재설치)에서 복원 → 잔액·거래가 똑같은지
- [ ] 다크 모드, 화면 회전
