# 구글 드라이브 봇 계정 만들기 (가족 자동 합산·드라이브 자동 백업용)

> 2.5부터 실제로 사용합니다. 1~5단계는 세윤님이 한 번만, 7~8단계는 가족 각자 폰에서 합니다.

머니플로우가 구글 드라이브의 **"머니플로우 가족" 폴더 하나만** 읽고 쓸 수 있게, 사람이 아닌 **봇 계정(서비스 계정)**을 만듭니다. 세윤님이 한 번만 하면 되고, 컴퓨터(PC 브라우저)에서 하는 것이 편합니다. 10~15분 걸립니다.

- 비용: 무료입니다 (결제 정보 등록 필요 없음).
- 봇은 **공유받은 폴더만** 볼 수 있습니다. 내 드라이브의 다른 파일은 볼 수 없습니다.
- 메뉴 이름은 구글이 가끔 바꿉니다. 아래와 다르면 비슷한 이름을 찾거나 화면 위쪽 검색창에 메뉴 이름을 입력하세요.

---

## 1단계. 프로젝트 만들기
1. https://console.cloud.google.com 에 세윤님 구글 계정으로 로그인합니다. 처음이면 약관에 동의합니다.
2. 화면 맨 위 프로젝트 선택 상자 → **새 프로젝트**
3. 프로젝트 이름: `moneyflow-family` (아무 이름이나 괜찮음) → **만들기**
4. 다시 맨 위 프로젝트 선택 상자에서 방금 만든 프로젝트를 고릅니다.

## 2단계. Google Drive API 켜기
1. 위쪽 검색창에 `Google Drive API` 입력 → 결과에서 **Google Drive API** 선택
2. **사용(Enable)** 을 누릅니다.

## 3단계. 봇 계정(서비스 계정) 만들기
1. 위쪽 검색창에 `서비스 계정` (Service Accounts) 입력 → **IAM 및 관리자 > 서비스 계정** 선택
2. **+ 서비스 계정 만들기**
   - 서비스 계정 이름: `moneyflow-bot`
   - **만들고 계속하기**
3. "역할 선택"(권한) 단계는 **비워 두고** 계속 → **완료**
   - 봇은 프로젝트 권한이 필요 없습니다. 드라이브 폴더 공유로만 권한을 줍니다.
4. 목록에 생긴 봇의 **이메일**을 확인합니다. 예: `moneyflow-bot@moneyflow-family.iam.gserviceaccount.com`

## 4단계. 열쇠 파일(JSON) 받기
1. 서비스 계정 목록에서 `moneyflow-bot` 을 누릅니다.
2. **키(Keys)** 탭 → **키 추가 → 새 키 만들기** → **JSON** → **만들기**
3. `moneyflow-family-xxxx.json` 같은 파일이 내려받아집니다. 이것이 **열쇠 파일**입니다.

> ⚠ 열쇠 파일은 비밀번호처럼 다루세요. 이 파일을 가진 사람은 봇에게 공유한 폴더에 접근할 수 있습니다.
> 인터넷 게시판·공개 채팅에 올리지 말고, 가족에게만 카카오톡 등으로 보내세요. (폴더 안의 머니플로우 파일은 가족 비밀번호로 한 번 더 암호화되어 있어서, 열쇠만으로는 내용을 읽을 수 없습니다.)
> 열쇠가 새었다고 생각되면 같은 화면에서 그 키를 **삭제**하고 새 키를 만들면 됩니다.

"키 만들기가 사용 중지되었습니다(조직 정책)" 같은 메시지가 나오면 회사·학교 계정으로 들어간 경우입니다. 개인 Gmail 계정으로 다시 해 주세요.

## 5단계. 드라이브 폴더 만들고 봇에게 공유
1. 구글 드라이브(https://drive.google.com 또는 드라이브 앱)에서 **새 폴더** → 이름 `머니플로우 가족`
2. 폴더 **공유** →
   - 가족 구글 계정 이메일 추가 → **편집자**
   - 봇 이메일(3단계 4번) 추가 → **편집자**
   - 봇 이메일에는 "알림 보내기"를 끄세요. (봇은 메일을 받지 않습니다. 켜 두면 경고가 나올 수 있어요.)
3. **공유** 를 누릅니다.

## 6단계. 앱에서 연결 시험 (선택)
각자 폰에서:
1. 열쇠 파일을 폰으로 받습니다 (카카오톡 "나에게 보내기" → 파일 저장 등).
2. 머니플로우 → 설정 → **가족 자동 합산 설정 (구글 드라이브)**
3. **① 연결 파일 불러오기** → 받은 JSON 파일 선택 → '불러왔어요'가 보이면 성공
4. **② 가족 폴더 고르기** → `머니플로우 가족` 선택
5. (아래 '문제가 있을 때 (연결 시험)' 칸) **시험 파일 만들기** → 저장 화면에서 **드라이브 → 머니플로우 가족 폴더**를 골라 저장
6. **연결 시험** → 네 단계가 모두 ✓ 이면 성공입니다. 결과 화면을 캡처해서 보내 주세요.

✗가 나오면 그 줄의 설명을 캡처해서 보내 주세요. 거기에 맞춰 고치겠습니다.

## 7단계. 가족 자동 합산 켜기 (가족 각자 폰, 2.5)
1. 열쇠 파일을 폰으로 받고 → 설정 → **가족 자동 합산 설정 (구글 드라이브)** → **① 연결 파일 불러오기** → **② 가족 폴더 고르기**에서 `머니플로우 가족` 선택
   - 가족 구글 계정도 5단계에서 폴더에 **편집자**로 공유돼 있어야 저장 화면에 폴더가 보여요. (가족 폰의 드라이브에서는 '공유 문서함'에 있어요)
   - 저장 화면에 폴더가 안 보이면: 드라이브 앱 → 공유 문서함 → `머니플로우 가족` ⋮ → **바로가기 추가** → 내 드라이브. 그러면 '내 드라이브'에서 고를 수 있어요.
2. **③ 내 이름 · 가족 비밀번호** → 이름(예: 엄마)과 **가족 모두 같은 비밀번호**(8자 이상)
3. **④ 내 가족 파일 만들기** → 저장 화면에서 왼쪽 메뉴(☰) → 드라이브 → `머니플로우 가족` 폴더 → 이름은 그대로 두고 **저장**
4. 끝. 이후에는 자동입니다.
   - 기록이 바뀌면 1분쯤 뒤 내 가족 파일을 봇이 새로 덮어써요.
   - 3시간마다(인터넷 연결 시) 다른 가족 파일이 바뀌었으면 받아서 **가족 합산** 화면에 반영해요.
   - 가족 합산 화면 위쪽 '구글 드라이브로 자동 합산 중'을 누르면 바로 합산합니다.
   - 가족 파일은 가족 비밀번호로 암호화된 백업이에요(메모 포함). 앱 잠금 PIN은 들어가지 않아요.

## 8단계. 드라이브 자동 백업 (선택, 각자 폰)
설정 → 백업 및 복원 → **구글 드라이브에 자동 백업** → 백업 비밀번호 → 저장 화면에서 같은 `머니플로우 가족` 폴더에 저장.
- 봇이 정한 주기(매일 또는 매주, 백업 화면에서 선택)마다 그 파일 하나를 새 백업으로 덮어써요. 예전 백업은 드라이브에서 그 파일 → ⋮ → 파일 정보 → **버전 관리**에서 받을 수 있어요(약 30일).
- 가족 폴더에 있지만 **백업 비밀번호**로 암호화돼 있어서 비밀번호를 모르면 열 수 없어요. 가족 비밀번호와 다르게 정해도 됩니다.

## 문제가 생기면
- "내 가족 파일을 찾지 못했어요": 파일을 지웠거나 아직 드라이브에 올라가지 않았어요. 1~2분 기다리거나 '내 가족 파일 만들기'를 다시 하세요.
- "'…' 파일을 열 수 없어요. 가족 비밀번호…": 그 가족과 비밀번호가 달라요. 같은 비밀번호로 다시 정하세요.
- 인터넷이 없을 때는 조용히 기다렸다가 연결되면 다시 시도해요.
