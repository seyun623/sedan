## 1단계 — 1.1 업데이트 (2~4주 사용 후, 피드백과 함께)
쓰다 보면 바로 체감되는 편의 기능입니다.

| # | 항목 | 이유 | 규모 |
|---|---|---|---|
| 1-1 | **자동 백업**: 한 번 고른 폴더(구글 드라이브 등)에 매주 자동으로 백업 파일 저장 + 오래 백업하지 않으면 알림 | 지금은 직접 백업해야 해서 잊기 쉬움. 폰 분실 대비 | 중 |
| 1-2 | **예산 알림**: 예산의 80%, 100%를 넘으면 알림 / 매월 1일 지난달 요약 알림 | 앱을 열지 않아도 지출 관리 | 중 |
| 1-3 | **자동 분류 규칙 관리**: 앱이 기억한 "보낸 곳 → 카테고리" 목록을 보고 수정·삭제, 특정 문자는 무시하도록 설정 | 1.0.2의 카테고리 기억 기능을 직접 다듬을 수 있게 | 소 |
| 1-4 | **외화 결제 알림**: 해외 결제 문자가 오면 "원화 금액을 입력해 주세요" 알림 → 누르면 입력 화면 | 지금은 외화 결제를 건너뜀 | 소 |
| 1-5 | **할부 결제 처리**: 할부 결제를 개월 수만큼 나눠 매달 지출로 기록하는 옵션 | 월별 지출이 실제 부담과 맞도록 | 중 |

## 기술 정리 (사용자에게 보이지 않음, 업데이트 때 함께 처리)
- 실제 기기 환경(에뮬레이터) 테스트를 CI에 추가: 암호화 DB, 잠금 화면 등 지금은 수동으로 확인하는 부분을 자동화
- 더 이상 권장되지 않는 라이브러리 함수 교체 (`hiltViewModel` 이전)
- 앱을 켜 둔 채 달이 바뀌면 홈 화면이 지난달을 보여 주는 문제 (앱을 다시 열면 정상)
- 앱 아이콘 정리 (안드로이드 13 이상 테마 아이콘용 단색 아이콘)
