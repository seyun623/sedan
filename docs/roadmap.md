## 카드사 데이터 연동에 대해
- 카드사에서 데이터를 자동으로 가져오는 마이데이터·오픈뱅킹 API는 금융위원회 허가를 받거나 등록된 사업자만 쓸 수 있어 개인 앱에서는 사용할 수 없습니다.
- 카드사 홈페이지 자동 로그인으로 긁어오는 방식은 약관 위반이고, 카드사 비밀번호를 저장해야 해서 하지 않습니다.
- 대신: 지금 결제는 문자·알림 자동 등록으로, 예전 내역은 엑셀 가져오기(2-3)로, 카드 실적은 앱이 직접 계산(1-6)합니다.

## 기술 정리 (사용자에게 보이지 않음, 업데이트 때 함께 처리)
- 실제 기기 환경(에뮬레이터) 테스트를 CI에 추가: 암호화 DB, 잠금 화면 등 지금은 수동으로 확인하는 부분을 자동화
- 더 이상 권장되지 않는 라이브러리 함수 교체 (`hiltViewModel` 이전)
- 앱을 켜 둔 채 달이 바뀌면 홈 화면이 지난달을 보여 주는 문제 (앱을 다시 열면 정상)
- 앱 아이콘 정리 (안드로이드 13 이상 테마 아이콘용 단색 아이콘)
