# Play Console 데이터 보안(Data safety) 작성 가이드

현재 버전 기준(서버 없음, AI 기능 꺼짐, 분석·광고 SDK 없음)입니다.

| 질문 | 답 | 근거 |
|---|---|---|
| 앱이 필수 사용자 데이터 유형을 수집하거나 공유하나요? | **아니요** | 모든 데이터는 기기 안에서만 처리·저장되고 개발자에게 전송되지 않음. Play 정의상 기기 안에서만 처리되는 데이터는 "수집"이 아님 |
| 데이터가 전송 중 암호화되나요? | 해당 없음 (전송 없음) | |
| 사용자가 데이터 삭제를 요청할 수 있나요? | 앱 안에서 직접 삭제 가능 / 앱 삭제 시 모두 삭제 | |

## 함께 확인할 것
- **권한 사용 설명**: 알림 접근(NotificationListenerService), 문자 수신(RECEIVE_SMS), 생체 인증, 인터넷
  - 인터넷 권한은 현재 AI 기능용으로만 쓰이며, 기능이 꺼져 있어 실제 통신은 없습니다.
- **AI 기능을 다시 켜면** 답이 바뀝니다: "앱 활동 > 기타 사용자 생성 콘텐츠(메모)"를 Google(Firebase AI)과 **공유**, 목적 "앱 기능", 전송 중 암호화 "예"로 표시해야 합니다.
- **SMS 권한**은 데이터 보안 양식과 별도로 "민감한 권한" 선언(Permissions Declaration)이 필요합니다. `release-checklist.md` 5번 참고.
