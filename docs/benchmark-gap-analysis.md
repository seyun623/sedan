# 다른 가계부와 비교: 우리에게 없는 기능 (2026-11-25)

비교한 앱은 뱅크샐러드, 토스, 편한가계부, 비주얼가계부, 머니매니저, 네이버페이 가계부입니다. 각 앱의 기능은 공개된 안내를 보고 정리했고, 앱 업데이트로 달라질 수 있습니다.

## 하지 않기로 한 것

- **마이데이터 직접 연결**: 금융위원회 허가를 받은 사업자만 할 수 있습니다. 대신 결제 알림 자동 등록과 카드사 가져오기(본인 로그인, 휴대폰 안에서 읽기)로 비슷한 효과를 냅니다.
- **스크래핑 대행 서비스 (CODEF 등)**: 카드사 아이디·비밀번호를 외부 회사에 맡겨야 하고, 정식 사용에는 사업자 계약이 필요합니다.
